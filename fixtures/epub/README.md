# EPUB Fixture Recipes

This directory contains synthetic, deterministic test books generated by
`scripts/generate-fixtures.mjs`. Do not edit `.epub` files by hand.

Run `pnpm run fixtures:generate` after changing a recipe and commit the generated
books and root `fixtures/manifest.json` together. `pnpm run fixtures:check`
regenerates the expected bytes in memory, validates checksums and CRCs, and
checks the format-neutral corpus structure.

All fixture content is dedicated under CC0-1.0. See `../manifest.json` for each
fixture's SHA-256 checksum, generation recipe, byte count, license, and expected
behavior tags.
