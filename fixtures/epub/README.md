# EPUB Fixture Corpus

This directory contains synthetic, deterministic test books generated by
`scripts/generate-epub-fixtures.mjs`. Do not edit `.epub` files or
`manifest.json` by hand.

Run `pnpm run fixtures:generate` after changing a recipe and commit the generated
books and manifest together. `pnpm run fixtures:check` regenerates the expected
bytes in memory, compares every checked-in file, validates checksums and CRCs,
and checks the minimum EPUB ZIP structure.

All fixture content is dedicated under CC0-1.0. See `manifest.json` for each
fixture's SHA-256 checksum, generation recipe, byte count, license, and expected
behavior tags.
